## ⚡ My Story

I started with blinking LEDs on an Arduino.
Now I build **production IoT products** that run on solar power,
talk over LoRa radio across long distances,
sync to the cloud via Firebase,
and are controlled from a Flutter app on your phone.

**TankMate** is my flagship — a complete embedded system I designed from scratch:
firmware, mobile app, security layer, and cloud backend. All of it.

I believe in building things that actually work in the real world.
Not just demos. Not just tutorials. **Real products.**
