# animated-invention

Experimental embedded and IoT innovation sandbox.
A space for prototyping new hardware ideas, testing sensor integrations,
and exploring the intersection of embedded systems and AI.

---

## What This Is

This repository is a collection of experiments and proof-of-concept projects
that don't yet belong to a dedicated repository. Ideas that start here may
graduate into full projects like TankMate.

---

## Areas of Exploration

- ESP32 peripheral experiments
- New sensor integrations
- Communication protocol testing (LoRa, BLE, ESP-NOW)
- AI edge inference on microcontrollers
- Solar and battery power optimization
- Flutter UI prototypes for hardware interfaces
